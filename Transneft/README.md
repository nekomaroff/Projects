# Анализ и прогноз показателей транспортировки

Проект посвящен анализу и моделированию данных, связанных с транспортировкой воды. Основной фокус - выявление факторов, влияющих на ключевые показатели процесса,  а также оценка возможности их прогнозирования на основе исторических данных.

В рамках работы акцент сделан не на формальное построение ML-модели, а на аналитический подход к задаче:
- понимание предметной области и бизнес-контекста
- исследование структуры и качества данных
- формирование и проверка гипотез
- интерпретация результатов с точки зрения применимости на практике

## Что сделано в проекте
- Проведён разведочный анализ данных (EDA): распределения, выбросы, взаимосвязи признаков
- Проанализировано влияние отдельных факторов на целевой показатель
- Сформированы и проверены гипотезы о поведении показателей транспортировки
- Построены и сравнены несколько моделей как инструмент анализа, а не самоцель
- Оценены ограничения данных и возможные направления улучшения модели

## Используемые инструменты
- Python
- pandas, numpy
- matplotlib, seaborn
- scikit-learn

## Результаты и выводы
Полученные результаты позволяют:
- понять, какие факторы вносят наибольший вклад в изменение целевого показателя
- оценить стабильность и предсказуемость процесса
- обозначить, какие данные необходимы для повышения качества прогнозов

Проект ориентирован на аналитическую интерпретацию и может быть использован
как основа для дальнейшего углублённого моделирования или бизнес-анализа.
