| Название проекта | Описание | Используемые библиотеки |
| :-- | :-- | :-- |
| **Сотрудники (Employee)** | Анализ факторов, влияющих на выгорание сотрудников, с фокусом на выявление ключевых признаков и оценку их вклада. Модели используются как инструмент для интерпретации и проверки гипотез о причинах выгорания. | *pandas, numpy, matplotlib, seaborn, scikit-learn, catboost, lightgbm, xgboost, optuna, scipy, tqdm, re* |
| **Клиенты (Churn)** | Исследование поведения клиентов и факторов, связанных с оттоком. Основной акцент сделан на анализ паттернов, сегментацию клиентов и интерпретацию результатов для понимания причин ухода, а не только на точность предсказаний. | *pandas, matplotlib, seaborn, scikit-learn, catboost, treex* |
| **Автомобили (Car)** | Анализ рынка автомобилей и факторов, влияющих на формирование цены. Проведено исследование зависимости стоимости от технических и эксплуатационных характеристик, с последующей оценкой предсказуемости цены. | *pandas, numpy, matplotlib, seaborn, scikit-learn, catboost, lightgbm, xgboost, tensorflow, keras* |
| **Доставка (Delivery)** | Анализ временных и операционных показателей доставки с целью выявления факторов, влияющих на задержки. Модели применяются для оценки устойчивости процесса и выявления узких мест. | *pandas, numpy, matplotlib, seaborn, scikit-learn, catboost, lightgbm, scipy, treex* |
| **Водохранилище (Transneft)** | Аналитическое исследование данных о хранении и объёмах воды: изучение динамики, факторов изменения и ограничений данных. Прогнозирование рассматривается как способ проверки стабильности выявленных закономерностей. | *pandas, numpy, matplotlib, seaborn, scikit-learn, catboost, lightgbm, xgboost* |
| **Цифры (Digit)** | Исследование задачи классификации изображений рукописных цифр с акцентом на понимание архитектур нейросетей, влияние параметров и интерпретацию ошибок модели. | *pandas, numpy, matplotlib, seaborn, scikit-learn, tensorflow, keras* |
