# Projects

| Название проекта | Описание | Используемые библиотеки |
| :-- | :-- | :-- |
| [Сотрудники](Employee) | Анализ факторов, влияющих на выгорание сотрудников, с дальнейшим предсказанием вероятности их ухода. | *pandas, numpy, matplotlib, seaborn, scikit-learn, catboost, lightgbm, xgboost, optuna, scipy, tqdm, re* |
| [Клиенты](Churn) | Исследование поведения клиентов и факторов, связанных с оттоком. Вероятностная оценка их ухода | *pandas, matplotlib, seaborn, scikit-learn, catboost, treex* |
| [Автомобили](Car) | Анализ рынка автомобилей и факторов, влияющих на формирование цены, с последующей оценкой предсказуемости цены | *pandas, numpy, matplotlib, seaborn, scikit-learn, catboost, lightgbm, xgboost, tensorflow, keras* |
| [Доставка](Delivery) | Анализ временных и операционных показателей доставки с целью выявления факторов, влияющих на задержки | *pandas, numpy, matplotlib, seaborn, scikit-learn, catboost, lightgbm, scipy, treex* |
| [Водохранилище](Transneft) | Аналитическое исследование данных о хранении и объемах воды: изучение динамики, факторов изменения и ограничений данных. Прогнозирование воды в водохранилище | *pandas, numpy, matplotlib, seaborn, scikit-learn, catboost, lightgbm, xgboost* |
| [Цифры](Digit) | Исследование задачи классификации изображений рукописных цифр с акцентом на понимание архитектур нейросетей, влияние параметров и интерпретацию ошибок модели | *pandas, numpy, matplotlib, seaborn, scikit-learn, tensorflow, keras* |
